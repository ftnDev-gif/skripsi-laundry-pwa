# User Stories - Sayangan Laundry PWA

1. **US-01 (Autentikasi):** Sebagai pengelola, saya dapat masuk ke sistem dashboard menggunakan akun yang aman.
2. **US-02 (Manajemen Transaksi):** Sebagai pengelola, saya dapat menambahkan data pelanggan, memilih layanan, menghitung total harga secara otomatis, dan menetapkan status bayar (Lunas/Kasbon).
3. **US-03 (Pembaruan Status):** Sebagai pengelola, saya dapat memperbarui tahapan cucian (Antrean -> Dicuci -> Disetrika -> Siap Diambil).
4. **US-04 (Cetak & Notifikasi):** Sebagai pengelola, saya dapat mencetak QR Code nota unik dan memicu sistem WhatsApp Gateway untuk mengirim pesan otomatis saat cucian selesai.
5. **US-05 (Tracking Publik):** Sebagai pelanggan, saya dapat memindai QR Code untuk melihat status cucian terkini secara real-time tanpa perlu proses login.
6. **US-06 (Rekapitulasi):** Sebagai pengelola, saya dapat melihat rekapitulasi omzet dan daftar piutang kasbon pelanggan.
